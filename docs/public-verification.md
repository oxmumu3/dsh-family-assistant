# 预览版验证范围

版本：0.2.0-preview.6；日期：2026-10-23。目标宿主 DeepSeek Harness 0.2.1-rc.2。

## 已完成

- 230 项自动测试通过：多成员数据与通道隔离、提醒/时区、持久化、Owner 管理对话与任务卡、明确授权转告、错误恢复、官方语音准备与录音生命周期、鉴权与请求体限制。
- 桌面/窄屏合成业务走查：自然语言建档、同卡修订、局部取消、失败恢复、草稿保存，以及录音→停止→转写→手动发送。浏览器合成走查与真实微信使用分开记录。
- 本机正式宿主通过原生插件管理器安装并启用；既有资料、配置、绑定及其他插件保持。真实模型管理对话和官方本地 ASR 已贯通。
- 单一 Owner 本人确认微信普通回复、一次性提醒、服务简报收到；这不代表其他成员收到了消息。
- 本人已确认真实麦克风输入完成；合成音源亦通过真实 MediaRecorder/转码/官方 ASR 回填草稿，识别不会自动发送。

preview.6 相比本机已验证的 preview.5 只调整公开分发文档、包版本与仓库元数据；运行代码不变。首次公开源码只包含检查后的源码、测试与公开说明，不包含开发者私有运行数据或内部历史。

## 仍需实际使用验证

- 多位真实长辈分别绑定后的并行对话、跨成员安排、日报/提醒实际收信。
- 长时间运行、电脑休眠/重启、平台会话有效期变化及不同设备环境。
- 新用户从公开下载地址完成安装和首次语音准备；以具体发行后的实测记录为准，不用开发机已安装状态替代。

## 当前能力边界

- 支持本人提醒与查询/取消、个人服务偏好、双向对话、经明确同意的转告。通用长期记事、可检索日程本、首次欢迎与自适应主动互动仍处于设计阶段，不能当作本版功能。
- Host 和电脑需要在线；微信接口接受不代表手机收到或已读。发送结果不明时不自动重试。
- 微信语音只处理通路已提供的转写文字。工作台麦克风使用官方本地识别，首次需要下载模型与本人系统权限。
